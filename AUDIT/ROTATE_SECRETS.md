# TRACE Secret Rotation Checklist

> [!WARNING]
> Due to historical exposure in project archives or hardcoded configurations, the following credentials must be immediately rotated manually in your cloud providers and environment secrets manager. Never commit any replaced values to git.

### 1. External AI & News API Keys
- **`GEMINI_API_KEY`** (Google AI Studio / Vertex AI)
  - *Action*: Generate a new Gemini API key in Google AI Studio, revoke the previous key, and store exclusively in App Hosting secrets or `.env`.
- **`GNEWS_API_KEY`** (GNews Developer Portal)
  - *Action*: Regenerate GNews API token in the GNews dashboard and revoke the previous token.

### 2. Administrative Security & Session Secrets
- **`ADMIN_PASSWORD`** (TRACE Sentinel Master Password)
  - *Action*: Set a strong 32+ character random passphrase in production environment variables (`ADMIN_PASSWORD`). The system will no longer accept fallback passwords (`password`).
- **`ADMIN_SESSION_SECRET`** (HMAC-SHA256 Token Signing Secret)
  - *Action*: Generate a cryptographically secure 64-byte random string (`openssl rand -hex 64`) for `ADMIN_SESSION_SECRET`. The system will refuse to start if this is missing or using default fallback strings.
- **`AI_ENGINE_INTERNAL_TOKEN`** (Node-to-FastAPI Internal Shared Secret)
  - *Action*: Generate a secure token used strictly across localhost between Express and the Python FastAPI bridge.

### 3. Firebase Authentication & Identity Toolkit Keys
- **`hashConfig.base64SignerKey`** (Firebase Authentication Scrypt Hash Signer Key)
  - *Action*: In the Firebase Console under Authentication > Settings > User account linking / Password hashing, rotate the project password hash signer key and update cloud configuration. Do NOT leave the signer key in `firebase.json`.
- **`FIREBASE_SERVICE_ACCOUNT_KEY`** (Firebase Admin SDK Private Key)
  - *Action*: In Google Cloud Console / Firebase Project Settings > Service Accounts, generate a new private key JSON for the service account and delete the old key ID.
- **`VITE_FIREBASE_API_KEY` / `FIREBASE_API_KEY`** (Firebase Web API Key)
  - *Action*: Verify API key restrictions in Google Cloud Console > APIs & Services > Credentials. Restrict this key to your Firebase App Hosting domain and mobile bundle IDs only.
